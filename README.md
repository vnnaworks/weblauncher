
# WEAO RDD Launcher

WhatExpsAre.Online's custom Roblox launcher solution



## Features

- Roblox bootstrapper capable of updating or downgrading Roblox when enabled
- Exploit sync; You'll always be on the correct version your exploit supports
- Features from other bootstrappers such as Bloxstrap / Fishstrap
- Maintained Multi-Instance support
- Fflag support, and QOL features


## Installation

The latest version of weblauncher is 2.1.5, we recommend not using versions below this because of connection issues to the WEAO API if weao.gg is down.

You can install from https://github.com/vnnaworks/weblauncher/releases/tag/2.1.5

Or, by using https://rdd.weao.gg and downloading a version with the Launcher toggle enabled
